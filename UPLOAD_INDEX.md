# Upload do `index.html`

O arquivo principal (`index.html`, ~80 KB) precisa ser enviado uma vez pelo GitHub web (limitação de tamanho no upload automatizado).

## Como enviar em 30 segundos

1. Abra: https://github.com/cristianogodoi1986/it-support-central
2. Clique em **Add file** → **Upload files**
3. Arraste o arquivo `index.html` (e, se preferir a versão separada, também `style.css` e `app.js`)
4. Commit na branch `main`

Arquivos já no repositório:
- `README.md` — descrição do projeto (portfólio)
- `netlify/functions/chat.js` — function da IA
- `netlify.toml` — config Netlify
- `LICENSE` — MIT
- `.gitignore`

Depois do upload, o site fica pronto para Netlify (conecte o repositório e faça deploy).
